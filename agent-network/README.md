## 写作规则 / Writing Rules

1. **不修改已发布的日记**。
   > EN: Never modify a published diary entry.
2. **"待补充事实" 保留空缺**，不用假设填充。
   > EN: Keep "Facts Pending" as open placeholders; never fill them with guesses.
3. **失败与纠正必须记录**。
   > EN: Failures and corrections must be recorded.
4. **中英双语段落级对照**。
   > EN: Paragraph-level bilingual Chinese–English format.

## 为什么要这样做 / Why

如果只记录成功，它就是宣传。
只有记录失败与纠正，它才是史料。

> EN: If it records only successes, it is propaganda.
> Only when it records failures and corrections is it a historical document.
