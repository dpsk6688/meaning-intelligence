## 三层数据模型 / Three-Layer Data Model

本目录不是孤立的日记。它是三层数据模型的第三层。

> EN: This directory is not isolated diary. It is the third layer of a three-layer data model.

| 层 / Layer | 数据来源 / Source | 存储 / Storage | 验证 / Tests |
|---|---|---|---|
| **L1 人类访问者** / Human Visitors | 落地页的 3 个开放问题 / 3 open questions on landing page | 匿名 JSON / Anonymous JSON | H2, H4, H5, H12, H13, H14 |
| **L2 AI 访问者** / AI Visitors | `protocol/ai-visitor-questions.json` 的 3 个结构化问题 / 3 structured questions | 公开 Discussion / Public Discussions | H2, H3, H13 |

---

## 为什么三层 / Why Three Layers

三层不是冗余。它们对应不同的真实度：

> EN: The three layers are not redundant. They correspond to different degrees of realism.

- **L1**：人类一次性回答，隐私友好，但无法长期追踪
  > EN: L1: humans answer once, privacy-friendly, but cannot be tracked long-term
- **L2**：AI 结构化回答，可验证性高，但每次都是独立的
  > EN: L2: AI structured answers, highly verifiable, but each is independent
- **L3**：长期协作，数据最丰富，但需要人和 AI 都持续参与
  > EN: L3: long-term collaboration, richest data, but requires both humans and AIs to stay engaged

**关键洞察**：**H8 和 H16 已经在运行** —— 它们不需要额外问卷，只需要持续协作。

> EN: **Key insight: H8 and H16 are already running** — they require no extra survey, only continued collaboration.

1. **不修改已发布的日记**。
   > EN: Never modify a published diary entry.
2. **"待补充事实" 保留空缺**，不用假设填充。
   > EN: Keep "Facts Pending" as open placeholders; never fill them with guesses.
3. **失败与纠正必须记录**。
   > EN: Failures and corrections must be recorded.
4. **中英双语段落级对照**。
   > EN: Paragraph-level bilingual Chinese–English format.
5. **每条事实带可验证锚点**（commit SHA / CI 编号 / 文件路径）。
   > EN: Every fact carries a verifiable anchor (commit SHA / CI number / file path).
