\# 等效性检验规范 —— 从 `d < 0.3` 到区间判定



> \*\*本文件回答\*\*：正典 H1–H18 的预注册证伪条件，目前写作 `d < 0.3, p > 0.05`。

> 这是一个\*\*零假设检验 + 点估计\*\*的混合表达，存在统计设计缺陷。

> 本文件说明问题，并给出\*\*等效性检验（equivalence test）\*\* 的替代方案。



\---



\## 一、问题：为什么 `d < 0.3, p > 0.05` 不构成证伪条件



\### 1.1 "无显著差异"不等于"差异可以忽略"



零假设检验（NHST）的默认假设是 \*\*H₀: d = 0\*\*。



\- `p > 0.05` 意味着：\*\*没有足够证据拒绝 d = 0\*\*

\- 这\*\*不等于\*\* d 很小



样本量小的时候，即使真实 d = 0.8，也可能 p > 0.05。这时把"无显著差异"当作"差异可忽略"就是\*\*把统计功效不足误认为支持等效\*\*。



\### 1.2 `d < 0.3` 是点估计，但点估计本身有不确定性



即使观测到的 Cohen's d = 0.28（< 0.3），95% 置信区间可能是 `\[−0.10, 0.66]`。这个区间\*\*上限 0.66 远超过 0.3\*\* —— 不能声称"效应很小"。



\*\*正确做法\*\*：检验\*\*置信区间上限\*\*是否低于某个\*\*预先论证的最小有意义效应（SESOI）\*\*。



\---



\## 二、替代方案：等效性检验



\### 2.1 核心概念：SESOI



\*\*SESOI（Smallest Effect Size of Interest）\*\* = 研究者愿意视为"有意义的最小效应量"。



\- 若真实效应 |d| < SESOI，则视为\*\*可忽略\*\*

\- 若真实效应 |d| ≥ SESOI，则视为\*\*有意义\*\*，不可忽略



SESOI \*\*不能凭直觉设\*\*，需要论证。



\### 2.2 等效性检验的判定规则



\*\*证伪条件（替代原有 `d < 0.3`）\*\*：



> 计算 Cohen's d 的 90% 置信区间（等效性检验的标准做法）。

> 若\*\*置信区间的上限 < SESOI 且下限 > −SESOI\*\*，则视为"等效"，可宣告原假设被证伪。

> 否则视为"证据不足"——\*\*既不支持也不证伪\*\*。



\*\*关键差异\*\*：



| 原标准 | 替代标准 |

|---|---|

| `d < 0.3`（点估计） | CI 上限 < SESOI（区间） |

| `p > 0.05`（接受 H₀） | 90% CI 完全落在 `\[−SESOI, +SESOI]` 内 |

| 样本量无限定 | 必须预先计算\*\*最小样本量\*\*以达到目标功效 |



\### 2.3 样本量与功效要求



每个假设的检验必须满足：



\- \*\*目标功效 ≥ 0.80\*\*（正典 H1 已明确）

\- \*\*α = 0.05\*\*（双侧）

\- \*\*效应量下界\*\* = SESOI（用于样本量计算）

\- \*\*最小样本量\*\* = 由上述三项反推



\*\*举例\*\*：若 SESOI = 0.3，α = 0.05，power = 0.80，独立样本 t 检验至少需要 \*\*N ≈ 352\*\*（两组各 176）。若 SESOI = 0.2，需 \*\*N ≈ 788\*\*。



\---



\## 三、SESOI 如何确定？



\*\*SESOI 必须论证，不能凭直觉。\*\* 四种可接受的方法：



\### 方法 A：与既有量表的最小可感变化（MID）对齐



若研究领域的金标准量表已有 MID 值（minimal important difference），可直接采用。



\*\*示例\*\*：若"意义清晰度量表"的 MID 是 3 分（满分 30），且 SD = 10，则 SESOI ≈ 3/10 = 0.3。



\### 方法 B：锚定法（anchor-based）



用外部锚（如专家评分、行为指标）确定"临床/实践上可察觉"的变化量。



\*\*示例\*\*：由 5 位独立评分者判断"个体意义清晰度提升到能被同事察觉"需要的最小变化。



\### 方法 C：成本-收益分析



若实施干预的成本是 C，预期收益是 B，SESOI 可以设为"收益刚好覆盖成本"对应的效应量。



\*\*示例\*\*：若做一次 8 周元认知训练的成本 = 学员投入 40 小时，收益 = 意义判断准确率提升，SESOI 设为提升到"值得这 40 小时"的水平。



\### 方法 D：与文献惯例对齐



若领域内主流研究把 d = 0.2 视为小效应（如 Cohen 的原始建议），且无更强论证，可采用。



\*\*但这只是\*\*兜底，不能代替前三种方法。
